# 二维参数化草图

基于 React 19、TypeScript 5.8、SVG 和 `ml-matrix` 的二维参数化草图示例。所有坐标和尺寸均以 **mm** 表示，画布中 X 向右、Y 向上；平移和缩放只改变视图，不修改模型坐标。

## 启动

```sh
npm install
npm run dev
```

生产构建与预览：

```sh
npm run build
npm run preview
```

运行测试：

```sh
npm test
```

## 操作

- **选择/拖动**：点击点或线段选择；按住点拖动，`Shift` 点击追加选择，`Delete`/`Backspace` 删除选中。
- **创建点**：切换工具后点击画布空白处；最多 20 个点。
- **连接线段**：切换工具后依次点击两个不同点；端点重合或距离小于 `1e-7 mm` 的零长线会被拒绝。
- **平移缩放**：滚轮缩放；按住 `Shift` 拖动画布或鼠标中键平移。
- **撤销重做**：添加、删除、距离修改和一次完整拖拽分别进入历史；新操作会清空重做栈。
- **示例**：左下角可载入“可改宽高矩形”和“定长连杆”。

## 约束

先在选择工具中选中几何，再从右侧面板添加：

- 点重合；
- 线段水平或竖直；
- 两条线段垂直；
- 两点距离，必须为有限正数；
- 固定点，锁定添加约束瞬间的坐标，固定点不能拖动。

点击约束列表中的一行会高亮对应点或线段。距离约束可直接修改数值；约束、点或线段可删除。删除点会级联删除关联线段以及所有引用它们的约束。未知引用、非法数值和零长线会被拒绝，且不会破坏上一份有效图形。

## 求解器

代码按职责拆分：

- `src/types.ts`：稳定身份与数据结构；
- `src/geometry.ts`：几何增删、引用和数值校验；
- `src/constraints.ts`：约束构造与等价关系检查；
- `src/solver.ts`：约束残差、解析 Jacobian、SVD 局部求解和秩/自由度统计；
- `src/history.ts`：撤销重做事务；
- `src/useSketch.ts`：成功后提交的编辑状态机；
- `src/SketchCanvas.tsx`：坐标变换、选择和拖拽交互；
- `src/ConstraintPanel.tsx`：约束添加、编辑、删除与高亮。

求解从当前形状出发，使用约束切空间中的软目标步与硬约束校正做局部最小变化解。拖动时鼠标位置只是低权重软目标，距离/固定等硬约束始终优先；若软目标不可达，点会沿允许的自由度靠近而不是牺牲尺寸。

容差和限制：

- 单约束绝对残差收敛容差：`1e-6 mm`（角度类为归一化点积残差）；
- 数值收敛 RMS：`1e-8`；
- 零长线阈值：`1e-7 mm`；
- 最大迭代次数：80；
- 独立方程数由 Jacobian 的 SVD 数值秩给出，剩余局部自由度为 `2 × 点数 - 数值秩`，冗余方程不会重复计为独立约束。

达到迭代上限但残差仍较大时，界面显示“未收敛”和残差最大的约束；这只表示局部数值求解未成功，不宣称数学上已证明无解。失败时保留此前有效的几何和约束；拖拽失败时保留拖拽开始前的最近有效位置。
