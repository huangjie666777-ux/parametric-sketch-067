# 参数化二维草图（Parametric Sketch）

一个基于 React 19 + TypeScript 5.8 + ml-matrix 的二维参数化草图网页：
修改尺寸或拖动点时，约束求解器保持重合、水平/竖直、垂直、距离和固定等几何关系。

## 运行

```sh
npm install
npm run dev       # 开发服务器
npm run build     # 类型检查 + 生产构建
npm test          # vitest 单元测试
npm run preview   # 预览生产构建
```

## 操作

坐标系以毫米为单位，右为 X 正方向、上为 Y 正方向。

- 工具栏：
  - **选择/拖拽**：单击选中点或线段；`Shift+点击` 追加选择；按住非固定点可拖动。
  - **加点**：在画布空白处单击创建点（最多 20 个）。
  - **连线**：依次单击两个点创建线段；同一点或重合点会被拒绝（零长线）。
  - **删除选中**或按 `Delete` / `Backspace`：删除点会同时删除关联线段与约束。
- 视图：鼠标滚轮缩放（光标处锚定），中键拖拽或 `Alt+左键` 拖拽平移。视图变换只影响显示，不改变坐标与尺寸。
- 约束：先选择几何，再在右侧面板添加。
  - 2 个点 → 点重合 / 两点距离（可输入初始尺寸）
  - 1 条线 → 水平 / 竖直
  - 2 条线 → 互相垂直
  - 1 个点 → 固定点（锁定添加时刻的坐标）
- 约束列表：显示约束与对应几何 id，距离约束可点击数值修改，可逐条删除；
  鼠标悬停约束行会在画布上高亮对应的点/线。
- 历史：添加、删除、改尺寸、拖拽都记录历史；`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`）重做。一次拖拽只产生一条历史，新操作清空重做栈。
- 示例：顶部可加载 **矩形示例**（宽/高是可修改的距离约束）与 **定长连杆示例**（拖动自由端，杆长保持不变）。

## 求解器

- 每个约束定义毫米量纲残差（重合/固定为 x、y 两个分量，距离为 `d − L`，
  水平/竖直为对应方向分量，垂直为单位向量点积）。
- 以当前形状为初值做高斯-牛顿局部求解：数值雅可比（自适应差分步长），
  通过 ml-matrix 的 SVD 求最小范数最小二乘解，适合欠约束系统。
- 拖拽时鼠标位置是**软目标**：先沿硬约束雅可比的零空间取切向步，
  再牛顿重投影回约束流形，因此不会为跟随光标牺牲距离等硬约束；
  软目标偏差尺度为 100 mm，收敛阈值约 0.5 mm，固定点不可拖动。
- **局部自由度** = `2 × 点数 − 硬约束雅可比秩`。冗余/重复约束用逐约束块的
  贪心 SVD 秩分析识别，只标记不重复计入；完全相同的约束在添加时直接拒绝。
- 新增约束或修改尺寸时先在工作副本上求解：**约束满足才提交**。
  失败时保留上一版有效图形与约束，状态栏列出残差最大的约束。
  迭代次数耗尽只代表“未收敛”，不代表已证明无解。

### 容差

- 硬约束收敛容差：`1e-6`（距离/坐标为毫米，垂直为归一化点积）。
- 提交判定要求各约束残差不超过 `1e-5`；拖拽流形重投影精度为 `1e-9`。
- 秩判定奇异值阈值：最大奇异值的 `1e-9` 倍。
- 最大迭代次数：80；数值微分步长为 `max(1e-5 mm, |坐标|·1e-3)`。

## 代码结构

- `src/sketch/types.ts`：点、线段、约束、文档、求解结果类型与稳定 id。
- `src/sketch/geometry.ts`：约束残差、几何引用解析、约束描述。
- `src/sketch/solver.ts`：SVD 高斯-牛顿求解、零空间拖拽、秩/自由度/冗余分析。
- `src/sketch/model.ts`：几何与约束的增删改、引用/数值/零长线校验、求解入口。
- `src/sketch/history.ts`：撤销重做与“一次拖拽一条历史”的事务管理。
- `src/sketch/examples.ts`：矩形与定长连杆示例。
- `src/ui/`：`useSketch.ts`（编辑事务编排）、`Canvas.tsx`（画布交互）、
  `ConstraintPanel.tsx`（约束面板与列表）、`App.tsx`、`styles.css`。
- `src/sketch/solver.test.ts`：求解、校验、删除联动、历史事务测试。
